# 325. Savings and transitional provisions
325. Where criminal proceedings are commenced before 5th December, 2016, the commencement date of the Penal Code (Amendment) Law, 2016 (Law 38 of 2016) and those proceedings later result in a default order being made after that date, the provisions of the Penal Code (2013 Revision) shall apply to those proceedings in respect of the default order.
Publication in revised and consolidated form authorised by the Cabinet this 13th day of March, 2018.
